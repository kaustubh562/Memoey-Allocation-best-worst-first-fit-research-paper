01 · RESEARCH OVERVIEW

Introduction

Memory management is an important function of an operating system. When multiple programs run on a computer, each program needs memory to store data and perform tasks. First Fit, Best Fit and Worst Fit are three memory allocation algorithms used to assign available memory to processes.

This research compares the three algorithms through simulation. Their performance is studied using successful process allocation, memory usage, remaining memory and the number of search checks. The objective is to understand how different allocation strategies affect memory management.

Research Objective

To simulate and compare the three allocation algorithms and understand their behaviour under different memory and process sizes.

04 · RESEARCH RESULTS

Key Findings

01

First Fit

First Fit selects the first suitable memory block. It is simple to implement and can perform fewer searches when a suitable block is found early.

02

Best Fit

Best Fit selects the smallest block that can accommodate a process. It may leave small gaps that are difficult to reuse for larger processes.

03

Worst Fit

Worst Fit selects the largest suitable block. It may leave a larger remainder, but this does not guarantee better overall memory usage.

Main Observation

The performance of each algorithm depends on the sizes and order of processes and the available memory blocks. No single algorithm is always the best.

06 · SUMMARY

Conclusion

The simulation demonstrates how First Fit, Best Fit and Worst Fit allocate memory differently. By testing different block and process sizes, users can compare allocation success and remaining memory. The results help explain why the choice of allocation algorithm depends on the workload and memory usage pattern.
